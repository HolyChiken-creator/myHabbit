# myHabbit 8.0 — Stability Update

- Новий незалежний завантажувач: Splash більше не може безкінечно залишатися на 0%.
- Динамічне завантаження app.js із жорстким cache-bust.
- Автоматичне очищення лише застарілих кешів myHabbit після активації нового Service Worker.
- Безпечне відновлення пошкодженого локального стану з резервною копією старого JSON.
- Модулі Telegram, синхронізації, контенту та офлайн-кешу не блокують перше відображення UI.
- Екран відновлення з кнопкою очищення кешу, якщо застосунок не підтвердив запуск за 6.5 секунди.
- Особисті дані не очищаються автоматично.
