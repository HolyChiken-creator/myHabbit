# myHabbit 9.0 — Warm Welcome

- Повністю оновлений стартовий екран без активного профілю.
- Канонічна пара персонажів і ведмедик у головній ілюстрації.
- Теплі картки входу без технічного перевантаження.
- JSON перейменовано у зрозуміле «Відкрити файл профілю».
- Збережені профілі показуються одразу на старті.
- Окрема дія керування профілями.
- Адаптація для телефона, планшета, ноутбука та широкого екрана.
- Safe-area для iPhone та Android WebView.
- М’які анімації з підтримкою prefers-reduced-motion.
- Оновлений Service Worker і кеш 9.0.
