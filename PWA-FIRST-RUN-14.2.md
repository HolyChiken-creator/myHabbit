# PWA First Run 14.2

- Навчання встановленню PWA показується до авторизації лише під час першого запуску.
- Автоматично визначаються Android, iOS/iPadOS та комп'ютер.
- На підтримуваних браузерах доступна нативна кнопка встановлення.
- Для Safari на iPhone/iPad показана інструкція через «Поділитися» → «На початковий екран».
- Після проходження або пропуску навчання воно більше не заважає запуску.
