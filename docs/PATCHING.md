# Правила Full та Update-only патчів

## Full ZIP

Містить увесь актуальний проєкт. Використовується для чистого завантаження, резервної копії або відновлення.

## Update-only ZIP

Містить лише:

- змінені файли;
- нові файли;
- `PATCH-MANIFEST.txt` зі списком змін;
- `DELETE-FILES.txt`, лише коли старі файли потрібно видалити вручну.

Структура шляхів усередині архіву повинна повністю збігатися з репозиторієм. Наприклад:

```text
public/app.js
src/worker.js
public/content/shop/catalog.json
```

## Робочий процес

1. Створити branch від актуального `main`.
2. Розпакувати Update-only ZIP у корінь репозиторію із заміною файлів.
3. Виконати `npm run check` та `npm run validate`.
4. Переглянути `PATCH-MANIFEST.txt` і, за наявності, `DELETE-FILES.txt`.
5. Зробити commit і Pull Request.
6. Після перевірки злити branch у `main`.

Update-only патч не повинен містити повну копію проєкту, дублікати або змінені назви незмінних файлів.
