# myHabbit 9.2 — Security & Sync

- Сервер блокує зміну складу сімʼї через загальний state-запит.
- Ролі користувачів, ID, дата створення та Telegram-привʼязка більше не приймаються з клієнського JSON.
- Звичайний учасник не може переписувати профілі інших членів сімʼї.
- Захищені поля сімʼї (ID, код, ліміт учасників) зберігаються сервером.
- Додано rate limiting для створення сімей, входу за кодом/PIN і частих записів стану.
- Примусовий Telegram bootstrap тепер доступний лише з Cloudflare Secret `TELEGRAM_BOOTSTRAP_SECRET`.
- Додано журнал заблокованих спроб зміни складу сімʼї.
- Оновлено версії клієнта та PWA-кешу до 9.2.0.

## Після завантаження на Cloudflare

За потреби примусового Telegram bootstrap додайте секрет:

```bash
npx wrangler secret put TELEGRAM_BOOTSTRAP_SECRET
```

Звичайна робота застосунку й автоматичне читання Telegram config не потребують цього секрету.
