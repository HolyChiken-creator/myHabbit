# myHabbit 8.1.2 — Passwordless JSON Login

- Додано швидкий JSON входу без пароля.
- Збережено окрему зашифровану резервну копію з паролем.
- Імпорт автоматично визначає тип JSON-файлу.
- Додано попередження, що швидкий JSON є ключем доступу.
- Вікно «Мої профілі» тепер відкривається поверх меню як окреме модальне вікно.
- Меню автоматично закривається перед відкриттям панелі профілів.
- Оновлено cache version до 8.1.2.
